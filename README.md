# SalesInsight PY — Análise e Visualização de Dados de Vendas

## Objetivo

Desenvolver uma aplicação em Python para carregar, tratar, analisar e visualizar dados de vendas, gerando métricas e informações relevantes para apoiar a análise de desempenho comercial.

## Tecnologias utilizadas

- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab
- Git e GitHub

## Estrutura do projeto

- `salesinsight.ipynb`: notebook com o desenvolvimento e as análises.
- `vendas.csv`: dataset utilizado no projeto.
- `README.md`: documentação do projeto.

## Dados utilizados

O projeto utilizará um dataset sintético de vendas, gerado em Python para fins educacionais. Os dados não representam transações reais.
